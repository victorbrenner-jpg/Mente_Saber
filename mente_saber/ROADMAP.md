# Roteiro de desenvolvimento

## Fase 1 — MVP local
- [x] Estrutura inicial do Streamlit
- [x] Cadastro e login básicos
- [x] Banco SQLite
- [x] Três perguntas gratuitas por conta
- [x] Seletor de disciplinas
- [x] Integração opcional com API de IA
- [x] Tela demonstrativa do plano mensal

## Fase 2 — Experiência de aprendizagem
- [ ] Botão “nova conversa”
- [ ] Renomear e listar conversas
- [ ] Exercícios e correção em modo separado
- [ ] Nível do estudante
- [ ] Feedback de resposta útil/não útil
- [ ] Tela de progresso

## Fase 3 — Conhecimento confiável
- [ ] Base de conteúdos revisados por disciplina
- [ ] Importação de materiais autorizados
- [ ] Busca de trechos relevantes (RAG)
- [ ] Referências e indicação de incerteza
- [ ] Avaliação de qualidade das respostas

## Fase 4 — Comercialização
- [ ] PostgreSQL gerenciado
- [ ] Pagamento recorrente integrado
- [ ] Webhooks assinados e idempotentes
- [ ] Verificação de status da assinatura
- [ ] Política de uso justo e limites de custo
- [ ] Painel administrativo
- [ ] E-mail de cobrança e recuperação de senha

## Fase 5 — Lançamento
- [ ] Hospedagem com HTTPS
- [ ] Monitoramento, logs e backups
- [ ] Política de privacidade e termos
- [ ] Testes de segurança e carga
- [ ] Teste-piloto com usuários
